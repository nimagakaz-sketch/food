# 🥗 Family Food Menu & Supermarket Price Comparator (Telegram Bot & FastAPI)

Комплексное решение для автоматизации планирования семейного рациона питания, гибкого управления продуктами (любимые, стоп-лист, аллергии) и **поиска строго актуальных цен в реальном времени** в трех торговых сетях (**Пятерочка**, **Магнит**, **Лента**). 

Включает бэкенд на **FastAPI**, Telegram-бота на **Aiogram 3.x** и полнофункциональный **Telegram Mini App (WebApp)** с дизайном на базе **Liquid Glass Kit** (плавающий тулбар из жидкого стекла с шейдерами `feDisplacementMap`, физической симуляцией капли и эффектом слияния жидкости).

---

## 🌟 Ключевые возможности

### 1. Расширенное управление списками (Любимые и Стоп-лист) с ручным вводом и 1-Click удалением
Доступно как в **Telegram Mini App**, так и непосредственно в чате бота (**в онбординге** и команде **/profile**):
- **Интерактивные списки на вкладке «Профиль»:**
  1. **Любимые продукты:** база для приоритетного составления меню всей семьи.
  2. **Стоп-лист / Исключения:** продукты, которые категорически исключаются из рациона.
  3. **Аллергии и ограничения:** медицинские противопоказания (глютен, лактоза, орехи и др.).
- **Добавление своих позиций любым способом:**
  - **Интерактивное поле ввода («Добавить свой продукт»):** пользователь может в любой момент написать название абсолютно любого нового продукта вручную, нажать кнопку добавления (`+ В любимые ❤️` или `+ В стоп-лист 🚫`), и он мгновенно сохранится в персональный профиль в БД.
  - **Предустановленный каталог по категориям:** структурированный рубрикатор базовых продуктов (*Мясо и птица*, *Рыба и морепродукты*, *Овощи и зелень*, *Молочные продукты и сыры*, *Бакалея*, *Грибы и ягоды*) для добавления в один клик.
  - **Быстрый ввод в чате Telegram:** возможность отправить `+ спаржа` (добавить в любимые) или `- лук` (добавить в стоп-лист), либо использовать кнопки `➕ В любимые` и `🚫 В стоп-лист`.
- **Удаление любых позиций в один клик:** 
  - На каждом теге продукта в Mini App и в клавиатуре бота размещена кнопка `✕`. При нажатии продукт мгновенно удаляется из БД, а меню автоматически пересчитывается без перезагрузки.
- **Параметры семьи:** интерактивный степпер количества человек в семье (от 1 до 10) и выбор периода (3, 5, 7 дней).

### 2. Поиск строго актуальных цен в супермаркетах онлайн
- **Парсинг и онлайн-котировки в реальном времени:**
  - Поиск актуальных на текущий момент цен в каталогах сетей **Пятерочка**, **Магнит** и **Лента**.
  - **Никаких устаревших, закешированных или захардкоженных прайс-листов:** модуль `RetailPriceSearcher` делает параллельные онлайн-запросы в каталоги ритейлеров с точными временными метками `⏱ Обновлено: YYYY-MM-DD HH:MM:SS`.
- **Детализированный расчет по каждому продукту:**
  - Отображает точную актуальную цену за конкретное требуемое количество продукта по каждому из магазинов (`Пят: 466 ₽ | Магн: 454 ₽ | Лента: 478 ₽`).
  - Минимальная цена по каждому продукту автоматически подсвечивается.
- **Итоговая стоимость общей корзины:**
  - Расчет полной стоимости недельной корзины для каждой торговой сети.
  - Выделение победителя с бейджем **«🏆 САМЫЙ ВЫГОДНЫЙ»** и расчет чистой экономии в рублях.
  - Умная рекомендация гибридной покупки (*«Купите мясо в Магните, а рыбу в Ленте — сэкономьте еще 280 ₽»*).
- **Кнопка ручного обновления:** В Mini App и в Telegram-боте доступна кнопка `🔄 Обновить цены онлайн`, повторно опрашивающая каталоги в реальном времени.

### 3. Генерация сбалансированного меню и автообновление по понедельникам
- **Умный подбор блюд с КБЖУ:** Завтраки, обеды и ужины с расчетом калорий, белков, жиров, углеводов, временем приготовления и подробным списком ингредиентов на семью.
- **Строгая фильтрация:** Алгоритм жестко исключает рецепты со стоп-листом и аллергенами и продвигает любимые ингредиенты.
- **Автоматическое обновление:** Каждый понедельник в 09:00 планировщик задач (`APScheduler`) обновляет меню на новую неделю и присылает уведомление.

### 4. Дизайн Liquid Glass (iOS 27 style) & Физический тулбар
- **Оригинальная архитектура Liquid Glass Kit (от Volodymyr `@vovnx`):**
  - **Шейдеры стекла на лету:** генерация карт смещения (`feDisplacementMap`) и спекулярных бликов через Canvas (`surf`, `profile`, `maps`, `filterFor`, `rebuild`) под точный размер элементов через `ResizeObserver`.
  - **Матовая основа (`.matte`):** `backdrop-filter: blur(8px) saturate(1.8)` с градиентным светящимся кантиком.
  - **Плавающий тулбар (`.dock` + `.bar`):** физическая пружинная симуляция движения жидкой капли (`.thumb` + `.lens` с клонированными вкладками) при свайпах и тапах.
  - **Эффект слияния жидкости (`.fil`):** край таб-бара динамически вытягивается навстречу капле с помощью генерируемого в реальном времени `clip-path: path(...)`.
  - **Интерактивная круглая кнопка (`.circle`):** физическое растяжение капли под пальцем с сопротивлением (`glassBtn`) для мгновенного обновления меню.
  - **Интерактивные стеклянные поля ввода:** `.glass-input`, `.tag-pill`, `.cat-pill`, пульсирующий индикатор живого поиска `.live-pulse` и тосты `.eggpop`.

### 5. Health Check и мониторинг (UptimeRobot)
- Корневой маршрут `@app.api_route("/", methods=["GET", "HEAD"])` возвращает легковесный ответ 200 OK без рендеринга при вызове `HEAD`.
- Выделенный маршрут `@app.api_route("/health", methods=["GET", "HEAD"])` возвращает `{"status": "ok"}` мгновенно для систем мониторинга без нагрузки на процессор и базу данных.
- Архитектура SQLite (с асинхронным драйвером `aiosqlite`) и готовность к подключению Supabase через переменные окружения.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка конфигурации
Скопируйте `.env.example` в `.env` и укажите токен Telegram-бота:
```bash
cp .env.example .env
```

В `.env`:
```ini

HOST=0.0.0.0
PORT=8000
DEBUG=false
```

### 3. Запуск тестов
```bash
python -m unittest test_app.py
```
> Все 4 теста успешно проходят проверку: Health Check (GET/HEAD), Onboarding, Menu Generation (с фильтрацией аллергенов и стоп-листа), Supermarket Comparison.

### 4. Запуск сервера и бота
```bash
python main.py
```
Сервер запустится на `http://0.0.0.0:8000`:
- **Telegram Mini App Web:** `http://localhost:8000/`
- **Health Check (UptimeRobot):** `http://localhost:8000/health` (поддерживает `GET` и `HEAD`)
- **API Документация Swagger:** `http://localhost:8000/docs`
- **Telegram Bot:** параллельно слушает сообщения и команды в фоне (`/start`, `/menu`, `/prices`, `/profile`).

## 📡 API Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| `GET`, `HEAD` | `/` | Главная страница Telegram Mini App (легкий 200 OK на HEAD) |
| `GET`, `HEAD` | `/health` | Легкий health check для UptimeRobot (`{"status": "ok"}`) |
| `GET` | `/api/profile/{user_id}` | Получение профиля и предпочтений семьи |
| `POST` | `/api/profile` | Сохранение анкеты и регенерация меню |
| `GET` | `/api/menu/{user_id}` | Меню пользователя на текущую неделю |
| `POST` | `/api/menu/generate` | Принудительная генерация нового меню |
| `GET` | `/api/prices/compare/{user_id}` | Расчет корзины в Пятерочке, Магните и Ленте |
| `GET` | `/api/prices/catalog` | Каталог актуальных цен на продукты |
| `GET` | `/api/status` | Статус аптайма, планировщика и пользователей |

# 🥗 Family Food Menu & Supermarket Price Comparator (Telegram Bot & FastAPI)

Комплексное решение для планирования семейного рациона питания и автоматического поиска самых выгодных цен на продукты в супермаркетах (**Пятерочка**, **Магнит**, **Лента**). Включает бэкенд на **FastAPI**, Telegram-бота на **Aiogram 3.x** и минималистичный **Telegram Mini App (WebApp)** с премиальным дизайном в стиле **Apple** (плавающий тулбар из жидкого стекла с анимированным индикатором).

---

## 🌟 Ключевые возможности

### 1. Интерактивный онбординг (Анкета предпочтений)
Последовательный сбор и сохранение профиля семьи через Telegram-бота (FSM-сценарий) и WebApp:
1. **Любимые продукты:** выбор базовых ингредиентов (курица, говядина, рыба, авокадо, паста, творог, рис, овощи) кнопками с галочками или произвольным текстом через запятую.
2. **Стоп-лист (нелюбимые продукты):** продукты, которые категорически исключаются из рецептов (лук, грибы, кинза, свинина, кабачки, субпродукты и др.).
3. **Аллергии и ограничения:** медицинские противопоказания и диеты (глютен, лактоза, орехи, морепродукты, яйца, вегетарианство).
4. **Размер семьи и период:** количество членов семьи (1, 2, 3, 4, 5+ чел.) для точного масштабирования граммовок порций, а также период планирования (3, 5, 7 дней).

### 2. Генерация сбалансированного меню и автообновление по понедельникам
- **Умный подбор блюд:** Завтраки, обеды и ужины с расчетом КБЖУ (калории, белки, жиры, углеводы), временем приготовления и подробным списком ингредиентов на семью.
- **Строгая фильтрация:** Полный запрет на попадание стоп-листа и аллергенов в рацион; приоритет отдается любимым продуктам.
- **Еженедельное автообновление:**
  - Фоновый планировщик задач (`APScheduler`) автоматически генерирует свежее меню для всех активных пользователей **каждый понедельник в 09:00** и отправляет дайджест в Telegram.
  - Проверка даты при запросе (`isocalendar week check`): гарантирует получение нового плана даже при перезапуске сервера.
  - Возможность ручной регенерации кнопкой «🔄 Новое меню».

### 3. Сравнение цен в трех торговых сетях (Пятерочка, Магнит, Лента)
- **Сводная корзина недели:** Все ингредиенты блюд суммируются с учетом весовых и штучных единиц (кг, л, дес., шт.).
- **Детализированный расчет:**
  - Цена по каждому супермаркету на каждый отдельный продукт (например: Куриное филе — Пятерочка: 466 ₽, Магнит: 454 ₽, Лента: 478 ₽).
  - Итоговая сумма корзины для каждой сети.
  - Выделение победителя с бейджем **«🏆 САМЫЙ ВЫГОДНЫЙ»** и расчет чистой экономии в рублях.
  - Умная подсказка гибридной корзины (*«Купите мясо в Магните, а рыбу в Ленте — сэкономьте дополнительно 280 ₽»*).

### 4. Дизайн Liquid Glass (iOS 27 style) & Физический тулбар
- **Оригинальная архитектура Liquid Glass Kit (от Volodymyr):**
  - **Шейдеры стекла на лету:** генерация карт смещения (`feDisplacementMap`) и спекулярных бликов через Canvas (`surf`, `profile`, `maps`, `filterFor`, `rebuild`) под точный размер элементов через `ResizeObserver`.
  - **Матовая основа (`.matte`):** `backdrop-filter: blur(8px) saturate(1.8)` с градиентным светящимся кантиком `::before`.
  - **Плавающий тулбар (`.dock` + `.bar`):** физическая пружинная симуляция движения жидкой капли (`.thumb` + `.lens` с клонированными вкладками) при свайпах пальцем и тапах.
  - **Эффект слияния жидкости (`.fil`):** край таб-бара динамически вытягивается навстречу капле с помощью генерируемого в реальном времени `clip-path: path(...)`.
  - **Интерактивная круглая кнопка (`.circle`):** физическое растяжение капли под пальцем с сопротивлением (`glassBtn`) для мгновенного обновления меню и пинга здоровья.
  - **iOS 27 карточки и цветные стеклянные теги:** компоненты `.scard`, `.schd`, `.scb`, `.tg` для удобного выбора ингредиентов и аллергенов, а также всплывающие тосты `.eggpop`.

### 5. Health Check и мониторинг (UptimeRobot)
- Корневой маршрут `@app.api_route("/", methods=["GET", "HEAD"])` возвращает легковесный ответ 200 OK без рендеринга при вызове `HEAD`.
- Выделенный маршрут `@app.api_route("/health", methods=["GET", "HEAD"])` возвращает `{"status": "ok"}` мгновенно для систем мониторинга без нагрузки на процессор и базу данных.
- Архитектура SQLite (с асинхронным драйвером `aiosqlite`) и готовность к подключению Supabase через переменные окружения.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка конфигурации
Скопируйте `.env.example` в `.env` и укажите токен Telegram-бота:
```bash
cp .env.example .env
```

В `.env`:
```ini
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
HOST=0.0.0.0
PORT=8000
DEBUG=false
```

### 3. Запуск тестов
```bash
python -m unittest test_app.py
```
> Все 4 теста успешно проходят проверку: Health Check (GET/HEAD), Onboarding, Menu Generation (с фильтрацией аллергенов и стоп-листа), Supermarket Comparison.

### 4. Запуск сервера и бота
```bash
python main.py
```
Сервер запустится на `http://0.0.0.0:8000`:
- **Telegram Mini App Web:** `http://localhost:8000/`
- **Health Check (UptimeRobot):** `http://localhost:8000/health` (поддерживает `GET` и `HEAD`)
- **API Документация Swagger:** `http://localhost:8000/docs`
- **Telegram Bot:** параллельно слушает сообщения и команды в фоне (`/start`, `/menu`, `/prices`, `/profile`).

## 📡 API Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| `GET`, `HEAD` | `/` | Главная страница Telegram Mini App (легкий 200 OK на HEAD) |
| `GET`, `HEAD` | `/health` | Легкий health check для UptimeRobot (`{"status": "ok"}`) |
| `GET` | `/api/profile/{user_id}` | Получение профиля и предпочтений семьи |
| `POST` | `/api/profile` | Сохранение анкеты и регенерация меню |
| `GET` | `/api/menu/{user_id}` | Меню пользователя на текущую неделю |
| `POST` | `/api/menu/generate` | Принудительная генерация нового меню |
| `GET` | `/api/prices/compare/{user_id}` | Расчет корзины в Пятерочке, Магните и Ленте |
| `GET` | `/api/prices/catalog` | Каталог актуальных цен на продукты |
| `GET` | `/api/status` | Статус аптайма, планировщика и пользователей |

# Avito Radar Bot — Telegram Mini App (TMA) Pro Edition

Современный профессиональный радар скидок Авито для перекупов и подборщиков с веб-интерфейсом **Telegram Mini App** в эстетике iOS / Liquid Glass и расширенным анализом лотов.

---

## 🚀 Новые возможности

1. **📱 Вкладка «Объявления» (Live Listings Feed)**:
   - Основная лента всех свежих поступлений с Авито в реальном времени.
   - Карточки в формате чистого торгового предложения: качественная фотография лота, модель, память, город, контрастная крупная цена и бейдж выгоды (если ниже рынка).
   - Быстрые кнопки: `[ ↗️ На Авито ]`, `[ ⭐ В избранное ]`, `[ 🧮 Маржа ]`, `[ 🚫 В ЧС ]`.
   - Быстрые фильтр-чипсы по моделям и наличию выгоды (`🔥 С выгодой`, `iPhone 13`, `iPhone 14`, `iPhone 12`, `iPhone 11`).

2. **🔥 Вкладка «Сделки» (Hot Deals)**:
   - Отфильтрованная лента исключительно выгодных предложений, цена которых ниже среднерыночной.

3. **⭐ «Избранное» перенесено в быстрый доступ**:
   - Перенесено в верхнюю панель в виде стеклянного бейджа-кнопки `⭐ Избранное (N)` и во встроенный верхний сегмент-бар.
   - Управление статусами лотов (`Сохранено`, `На проверке`, `Куплен`, `Перепродан`) и быстрые заметки перекупа.

4. **💎 Плавающий тулбар iPhone Liquid Glass**:
   - Парящий док в стиле современного Apple iOS Liquid Glass: размытие фона (`blur(32px) saturate(210%)`), зеркальный кант, плавный пружинный индикатор активной вкладки (`cubic-bezier(0.34, 1.56, 0.64, 1)`) и пружинный отклик иконок.

5. **🧮 Интерактивный калькулятор маржи и ROI**:
   - Моментальный расчет чистой прибыли, маржинальности (%) и окупаемости инвестиций (ROI).
   - Быстрые шаги `[-1k]` / `[+1k]` и сохранение готового расчета прямо в Избранное.

6. **📸 Чистые торговые предложения в Telegram**:
   - Лаконичные уведомления с фото: Бейдж выгоды ➔ Название ➔ Крупная цена ➔ Рыночная цена/профит ➔ Город ➔ Кнопки. Без лишнего шума и дефектного мусора.

## 📂 Структура проекта

```text
avito_bot/
├── server.py              # Веб-сервер управления и REST API
├── worker.py              # Фоновый парсер каталога Авито + Telegram Bot
├── tasks.json             # Настройки поисковых задач
├── deals.json             # Найденные горячие скидки
├── favorites.json         # Избранные лоты со статусами и заметками
├── blacklist.json         # Заблокированные продавцы
├── proxies.txt            # Список прокси для ротации (HTTP/SOCKS5)
├── items_store.json       # Каталог спарсенных объявлений
├── price_cache.json       # Кэш цен для предотвращения дубликатов
├── requirements.txt       # Python зависимости
└── web/                   # Telegram Mini App
    ├── index.html         # Разметка приложения в стиле Telegram iOS
    ├── css/style.css      # Стилизация Liquid Glass & iOS Inset Grouped
    └── js/app.js          # Логика табов, калькулятора и API
```

## 🛠️ Установка и запуск

### 1. Установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск веб-сервера
```bash
./venv/bin/python3 server.py 8088
```
После запуска откройте в браузере или подключите в BotFather:
👉 **http://127.0.0.1:8088**

### 3. Автономный запуск воркера
```bash
./venv/bin/python3 worker.py
```
Или однократный скан:
```bash
./venv/bin/python3 worker.py --once
```
